# How to cite pubTreeServer

[← Project home](../README.md)

If you use pubTreeServer, follow the official project site for the latest publication or citation details:

- [pubTreeServer homepage](https://mgs.microbialgenomic.cn/pubTreeServer)
- [Project website](https://www.microbialgenomic.cn/)

A software citation metadata file, [`CITATION.cff`](../CITATION.cff), is included to enable GitHub's **Cite this repository** menu. It identifies the software and published contact, **without fabricating a DOI, journal reference, version number, release date or GitHub repository owner**.

Until a formal associated software article or DOI is available, you can cite the pubTreeServer website and your date of access according to the guidelines of your journal. Update these files after a verified bibliographic citation becomes available.
