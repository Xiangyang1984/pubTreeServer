Save and share configuration

The Save Configuration function saves the current visualization and annotation settings, including layout, tree state, annotation data, colors, legends, scale bar, edited tree position, and other interactive states. The saved URL can be shared with collaborators, enabling team members to review and refine the same configured figure.

Unified workflow

Two ways in. One visualization workspace.

MODE 01 / GENOMIC INPUT

Genome → phylogeny → TreeVisualizer

Provide NCBI assembly accessions or upload FASTA genome assemblies. pubAutoTree infers a phylogenetic tree and passes it to the visualization interface.

Start with genomes ↗
MODE 02 / EXISTING TREE

Newick → TreeVisualizer

Upload a pre-built `.nwk` phylogeny to immediately begin editing, annotation, layout customization and figure export.

Start with a Newick tree ↗
